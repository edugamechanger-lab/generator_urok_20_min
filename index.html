Заполните паспорт выше. Промпт соберется автоматически.

Шаг 2. YouLearn — получите резюме видео

YouLearn — сервис для работы с учебными материалами. Он умеет создавать резюме, заметки, викторины, флеш-карты и другие форматы на основе добавленного материала. В этой цепочке нам нужна функция «Резюме».

Открыть YouLearn ↗

Что сделать: Добавить материал → По ссылке → вставить ссылку на видео → Резюме → Скопировать.

Здесь отдельный промпт не нужен.

↓ Переносим в Qwen / ChatGPT резюме видео ↓
